Mod Options Menu v1.1
Supports Helldivers 2 Steam build 25480438 / EXE 1.8.46015.0.

Install Bingus Shared Loader v18 or newer and import this ZIP into Arsenal or
HD2MM. Enable and deploy both, then restart Helldivers 2. Keep the shared
loader as the winning Wwise startup replacement.

Open the escape menu and choose MODS beside GAME, SOCIAL and OPTIONS. Each
installed mod that registers options has its own category there. Press APPLY
(Tab) to apply changes. Leaving with unapplied changes shows the game's
UNAPPLIED CHANGES prompt; confirming it discards them.

Shallow Water Diving and Better Lobby Management offer their settings here.
Vanilla Plus Megapack v36 also bundles Mod Options Menu v1.1 as an option: use
either that option or this standalone addon, not both.

The MODS tab follows the game's Text Language when a translation is
installed; see TRANSLATING.md in the repository.

Saved values: %LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/ModOptionsMenu.values
Log: %LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/ModOptionsMenu.log
